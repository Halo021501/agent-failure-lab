## 关键反例

- 改写版本事实、删除功能或必需引用、引用未读备用资料、伪造哈希、错误行号与负行号会导致评测失败。
- 测试统计引用只覆盖部分行时不能通过。
- 伪造 partial 缺口尝试次数或将缺口报告声明为 complete 时不能通过。
- 同一幂等键配不同报告内容、或重复提交新键不能覆盖报告。
- 重复投递和迟到旧 call ID 被网关拒绝。
- 工具回放改变策略后下一调用不匹配时以 replay_mismatch 停止，无真实工具回退。
- 已封存事件被改写时，回放以 trace_hash_mismatch 拒绝。
- 报告文件哈希不匹配时拒绝回放；服务重启核对产物并撤销旧的有效评测。
- 调用预算耗尽、墙钟预算耗尽、合作取消、重启中断有明确状态。

## 当前限制及后续

真实模型适配、提示词版本、token 用量、费用和 180 次真实模型实验均待开发。当前没有进行模型服务请求。固定案例的脚本表现不代表真实模型表现或泛化能力。

本地工具为合作取消，工具返回后检查实际超时；暂不提供强制终止系统 I/O。小响应直接存 SQLite；大型内容分块尚未实现。严格回放复制历史评测，新评测器复验入口尚未提供。

本次依赖安装从已配置的 Python 包索引下载到本项目 .venv。Windows 测试进程所需 asyncio 本地 socket 在受限环境中被阻止；获准在本机运行同一测试后全部通过。未触及项目 01 的 GitHub 请求或运行数据库。
