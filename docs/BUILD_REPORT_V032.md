## 当前行为

已结束实验使用 Store 内的 LRU 快照缓存，最多 8 个实验，每个不超过 600 次运行。快照保存已解析运行与汇总，运行页只复制当前页。失效依据包括本连接实际写入修订、SQLite data_version 和每份报告的 mtime/ctime/大小/inode；完整性维护写入单独计数。不同连接修改记录、报告变化、追加评测或执行写入后重新计算。活动实验不复用快照；导出与比较强制核验。选中运行的强制核验若发现完整性变化，会移除相关概览快照；结果未变时保留缓存。

每轮检查只解析一次根目录，仍逐个解析报告路径并检查目录约束，避免重复开销。读出的对象做深复制，调用方不能修改缓存。概览仍以完整实验统计分母，分页及游标行为不变。首次或失效后仍读取全实验；热读仍检查所有报告，同库其他实验的执行写入也会保守失效。文件状态缓存不是连续监控，也不能保证识别状态信息完全未变化的外部内容替换；正式导出/比较强制读内容核验。

事件浏览增加以下可选协议，原完整事件 API 默认行为保留：

| 请求 | 行为 |
| --- | --- |
| `GET /api/runs/{id}/events?preview=true&after_seq=0&limit=100` | 合法事件返回最多 512 个 Unicode 码点的 payload_preview、payload_chars、payload_sha256 和截断标志；不返回整个 payload |
| `GET /api/runs/{id}/events/{seq}/payload?sha256={hash}&offset=0&limit=4096` | offset/limit 按 Unicode 码点计算，最多 4096；返回 text、total_chars、next_offset 和原文本 SHA256；最后一段 next_offset 为 null |

分段哈希与预览绑定原数据库文本；载荷改变返回 payload_changed，防止混合快照。损坏事件仍返回诊断占位，分段入口拒绝损坏载荷和完整性异常运行。网页展开时读取第一段，上一段/下一段替换文本；运行切换后迟到响应不能写入当前界面。引用跳转也使用预览，打开对应读取事件后按需加载载荷。封存事件、资料、工具行为、评测器、提示词未修改。
