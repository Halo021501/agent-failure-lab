## M0 · 契约与工程（0.5—1 天）

- [x] 初始化 Python 项目、独立虚拟环境、依赖锁和运行数据忽略规则。
- [x] 建立案例、报告、事件、实验配置和评测结果 schema v1。
- [x] 冻结公开资料与隐藏真值的访问边界。
- [x] 实现配置加载、预算检查与 CLI 入口。
- [x] 制作 N01、F-T01、F-M04 的资料、故障定义与预期断言。
- [x] 验证合法案例可加载，非法路径、重复 ID 和错误定义被拒绝。

退出：3 个种子案例契约明确，可在不调用模型的条件下校验。

## M1 · 离线闭环（2—3 天）

- [x] 实现 list_sources、read_source、write_report。
- [x] 实现五类故障、触发阶段、匹配计数、逻辑时钟和种子。
- [x] 区分原始响应、交付响应、故障触发和重复投递。
- [x] 实现 runner 状态机、工具预算、终止和合作取消。
- [x] 实现无恢复基线、有限恢复基线；网关禁用隐式重试。
- [x] 保存事件、产物、幂等键和哈希，检测中断提交。
- [x] 补齐 30 个案例及独立事实/引用断言。
- [x] CLI 输出逐案结果与第一份离线证据。

退出：恢复基线 30/30 处置通过（25 完整、5 正确 partial），无恢复基线暴露故障失败；模型请求为 0。

## M2 · 回放与比较（1—1.5 天）

- [x] 实现事实、引用、缺口、产物和终态评测。
- [x] 加入事实错误、伪造引用、篡改哈希等评测反例。
- [x] 实现 trace_replay，保留原事件、响应和产物。
- [x] 实现 tool_replay，按顺序严格匹配调用，不命中则停止。
- [x] 实现 fresh_run 及原运行关联记录。
- [x] 计算恢复率、覆盖率、完整成功、处置通过、耗时和成本。
- [x] 实现实验可比性检查、逐案比较及 JSON/CSV 导出。
- [x] 验证正确 partial、未激活故障、N/A 和 unknown 的聚合规则。

退出：严格回放零外部调用且数据一致；回放不匹配显式失败；不可比实验不给提升结论。

## M3 · 本地界面（1.5—2 天）

- [x] 实现本地 FastAPI 接口、后台实验队列和状态轮询。
- [x] 实现案例列表与单案/批量运行。
- [x] 实现时间线、原始/交付响应、报告和逐项断言。
- [x] 实现取消、重启后 interrupted 状态和持久化恢复检查。
- [x] 实现回放页面、比较页面和导出入口。
- [x] 完成 setup.ps1、start.ps1，端口默认 8767 且可配置。
- [x] 浏览器验证运行、停止、回放、比较、导出和重启保留记录。

退出：完整离线实验可以通过本地中文界面操作和复查。

## M4 · 真实模型（1—1.5 天）

- [ ] 根据可用模型配置确定首个供应商并锁定适配依赖。

- [ ] 实现两版提示词、实验版本和相同预算下的比较。
- [ ] 实现模型超时、错误、取消、请求/token 上限和成本未知处理。
- [ ] 在 6 个代表案例完成接口检查，核对实际请求与工具动作。
- [ ] 真实模型结果与离线脚本结果分开显示和导出。

退出：真实请求和响应可追溯，模型不可用时离线功能仍正常。
